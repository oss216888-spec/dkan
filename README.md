# دكّان على Supabase

```
الموقع (site/)  ⇄  Supabase (قاعدة بيانات + دوال)  ⇄  عامل واتساب على حاسبك (worker/)
```

## ١) قاعدة البيانات
1. أنشئ مشروعًا في supabase.com.
2. افتح **SQL Editor** > **New query**، والصق محتوى `supabase/schema.sql` كاملًا، ثم **Run**.
3. لو ظهر خطأ، انسخ نصه كما هو (لم أستطع تجربة الملف على Postgres حقيقي).

## ٢) المفاتيح (من Settings > API)
- `Project URL` و `anon public` ← ضعهما في `site/config.js`. هذان آمنان للعلن.
- `service_role` ← ضعه في `worker/.env` فقط. **سري جدًا**: لا تضعه في الموقع ولا ترسله لأحد.

## ٣) عامل الواتساب (على حاسبك)
1. ثبّت Node.js 18 أو أحدث.
2. في مجلد `worker`: انسخ `.env.example` إلى `.env` واملأ القيمتين.
3. انقر مرتين على `start-worker.bat`. أول مرة ينزّل المكتبات، ثم يظهر باركود: امسحه بجوال المنصة (واتساب > الأجهزة المرتبطة > ربط جهاز).
4. اترك النافذة مفتوحة. لو أُغلقت أو انقطع الإنترنت، الرسائل تنتظر في الطابور وتُرسل لما يرجع.
5. للتجربة بدون واتساب: `WORKER_MODE=mock` في `.env`.

## ٤) الموقع
- للتجربة: افتح `site/index.html` من الحاسب.
- للنشر: ارفع مجلد `site` (الملفان index.html و config.js) على استضافة ثابتة مجانية (Render Static Site أو Cloudflare Pages أو GitHub Pages).
- رابط المتجر للعملاء: `رابط-موقعك/?s=اسم-المتجر`.

## ما يعمل الآن
- تسجيل التاجر برمز واتساب، وكلمة مرور (مخزّنة مشفّرة)، وبقاء الدخول بعد تحديث الصفحة.
- حفظ المتجر والمنتجات والإعدادات في القاعدة، وظهور المتاجر لأي عميل.
- الطلبات تُحسب وتُتحقق في الخادم (الأسعار والمخزون والتوصيل)، وتصل التاجر برسالة، ويصل العميل إيصال استلام.
- تغيير حالة الطلب يرسل رسالة للمشتري. لوحة التاجر تتحدث تلقائيًا كل ٨ ثوانٍ.
- لو أرسل العميل «طلب #1001» لرقم المنصة، يرد العامل بحالة الطلب.

## تنبيهات
- **حسابات العملاء** (في المتجر) لم تُحفظ في القاعدة بعد، وتضيع بتحديث الصفحة. الطلب نفسه يُحفظ.
- **الصور** تُحفظ داخل بيانات المتجر. مع نمو المتاجر انقلها إلى Supabase Storage.
- **الحماية من الإزعاج:** ٣ رموز كل ١٠ دقائق لكل رقم، و٣٠ رمزًا عامًا كل ١٠ دقائق، و٥ محاولات لكل رمز، و٨ محاولات دخول خاطئة تقفل ١٠ دقائق. لو فتحت الموقع للعامة أضف CAPTCHA.
- **المشاريع المجانية في Supabase تتوقف بعد أسبوع بلا نشاط.** العامل يستعلم كل ٣ ثوانٍ فغالبًا يمنع هذا، لكن تأكد.
- **واتساب بالباركود غير رسمي:** استخدم رقمًا مخصصًا للمنصة، ولا ترسل رسائل دعائية.
